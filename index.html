🌐 O que é HTTP?

HTTP significa Hypertext Transfer Protocol. É um dos principais protocolos utilizados para comunicação entre clientes e servidores na internet.

Como funciona?

Quando você acessa um site, o navegador envia uma requisição para um servidor. O servidor processa essa requisição e retorna uma resposta, que pode conter uma página HTML, imagens, arquivos ou outros dados.

GET Solicita dados
POST Envia dados
PUT Atualiza dados
DELETE Remove dados
