02 — HTTP

Como a Web conversa?

O HTTP organiza a comunicação entre quem solicita uma informação e quem fornece essa informação.

💻

Cliente

O navegador cria e envia uma requisição.

→
🌐

Internet

A comunicação acontece através da rede.

→
🖥️

Servidor

O servidor processa e devolve uma resposta.

Métodos

As principais ações

GET

Buscar

Solicita uma informação ou recurso disponível.

POST

Enviar

Envia informações ao servidor para processamento.

PUT

Atualizar

Solicita a atualização de um recurso existente.

DELETE

Remover

Solicita a remoção de determinado recurso.

REQUISIÇÃO HTTP example.com

03 — Respostas

O servidor responde.

Os códigos de status ajudam o cliente a entender o resultado de uma requisição.

2xx

Sucesso

A requisição foi recebida e processada.

3xx

Redirecionamento

É necessária uma ação adicional.

4xx

Erro do cliente

Existe um problema na requisição.

5xx

Erro do servidor

O servidor encontrou um problema.

04 — História

De uma ideia à Web.

Uma visão resumida de alguns momentos importantes da evolução da World Wide Web.

1989

A proposta da World Wide Web

Tim Berners-Lee apresentou uma proposta para um sistema que facilitaria o compartilhamento de informações.

1991

A Web começa a ganhar forma

A primeira página Web tornou o conceito mais concreto e abriu caminho para novos navegadores e servidores.

ANOS 1990

A expansão da Internet

A Web passou a crescer rapidamente, com mais usuários, páginas e serviços conectados.

ATUALMENTE

Aplicações completas no navegador

A Web evoluiu para plataformas capazes de executar aplicações, serviços e experiências cada vez mais complexas.

Entender a Web é entender como computadores se comunicam.

O HTTP é uma das bases da comunicação na Web. Estudar seu funcionamento ajuda a compreender o caminho percorrido por uma informação desde o navegador até o servidor e de volta ao usuário.
