02 — TECNOLOGIA

Como o HTTP funciona?

O HTTP permite que diferentes dispositivos troquem informações através de uma estrutura baseada em requisições e respostas.

💻

Cliente

O navegador envia uma requisição.

→
🌐

Internet

Os dados são transportados pela rede.

→
🖥️

Servidor

O servidor processa a requisição.

Métodos HTTP

GET

Solicita informações ou recursos disponíveis no servidor.

POST

Envia informações para o servidor para criação ou processamento.

PUT

É utilizado para atualizar determinado recurso.

DELETE

Solicita a remoção de determinado recurso.

03 — RESPOSTAS

Códigos de status HTTP

Os códigos de status informam o resultado de uma requisição feita ao servidor.

2xx

Sucesso

A requisição foi recebida, compreendida e processada.

3xx

Redirecionamento

É necessário realizar uma ação adicional para concluir a requisição.

4xx

Erro do cliente

A requisição possui algum problema ou não pode ser processada.

5xx

Erro do servidor

O servidor encontrou um problema ao processar a requisição.

04 — HISTÓRIA

Uma breve história da Web

A evolução da Web transformou completamente a forma como pessoas e computadores compartilham informações.

1989

Surge a proposta da World Wide Web

Tim Berners-Lee apresentou uma proposta para um sistema que permitiria compartilhar informações através de uma rede.

1991

Primeira página da Web

A primeira página da World Wide Web tornou o conceito acessível através de um navegador.

Anos 1990

Crescimento da Internet

Navegadores e servidores começaram a se popularizar, aumentando rapidamente a quantidade de páginas disponíveis.

Hoje

Uma Web altamente interativa

Atualmente, aplicações Web podem executar sistemas completos diretamente no navegador, utilizando diversas tecnologias.
